# qyn-skills

一套给"时间管理值守 Agent"看的**作业手册**（Markdown 技能）。每个技能说明一件事怎么干、
边界在哪、踩过什么坑，由 Agent 按需加载。

| 技能 | 什么时候用 |
|---|---|
| `qyn-time/` | 日常：把话变成日期/周期任务，出规划与待办 |
| `qyn-write/` | 写入入口的形状速查（不确定 JSON 怎么写时看它） |
| `qyn-timetable/` | 课表录入：读图 → 逐格抄 → 标停课/调课 → 回读核对 |
| `qyn-phone/` | 手机通道：发消息、收消息、看图片 |
| `office-pdf/` | 读 PDF（作业通知、课件） |

`AGENTS.md` 是**每轮都在上下文里**的常驻守则：红线、任何时候都不能忘的几条、
什么时候该加载哪个技能。

## 为什么技能要写成文档

模型的行为靠提示词约束是不可靠的 —— 所以这里只写**可复述、可验收**的流程：
先做什么、再怎么核对、什么情况必须停下问人。真正的机制（日期、时刻、校验、滚转）
在内核里，不在文档里。
